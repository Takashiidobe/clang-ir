# clang-ir-types

[![crates.io](https://img.shields.io/crates/v/clang-ir-types.svg)](https://crates.io/crates/clang-ir-types)
[![docs.rs](https://docs.rs/clang-ir-types/badge.svg)](https://docs.rs/clang-ir-types)

Generated Clang IR (CIR) type definitions: enum attributes, CIR types,
attributes, and typed operations.

This crate is generated by [`clang-ir-types-gen`](https://github.com/Takashiidobe/clang-ir)
by reading tablegen code from `llvm-project/clang/include/clang/CIR/Dialect/IR`.

The version number is denoted by `{crate_version}-{counter}-{llvm-commit-hash}`.
This is so version of clang-ir can pick the newest version they work
with.
